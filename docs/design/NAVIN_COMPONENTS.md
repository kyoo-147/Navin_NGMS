## Rules
1. Reuse before creating.
2. No page-specific button styles.
3. No hardcoded random colors.
4. Lucide only.
5. No visual-only cards.
6. Components do not own business logic.
7. Mail and Control share primitives, not page templates.
8. Components need loading/disabled/error/overflow behavior where relevant.
